# Reactions & Pins

## Emoji Reactions

Hover over a message to reveal the reaction button. Click it to open the emoji picker, then select an emoji. Your reaction appears as a pill below the message showing the emoji, count, and who reacted.

- Click an existing reaction pill to add your vote (or remove it if you already reacted).
- Reactions update in real time for all channel members.

## Pinned Messages

Pinning highlights important messages so they're easy to find later.

### Pinning a Message

Hover over a message and click the pin icon. The message is pinned to the channel. All channel members can pin messages.

### Viewing Pinned Messages

Click the pin icon in the channel header to open the pinned messages panel. It shows all pinned messages in the channel, newest pin first.

### Unpinning

Click the unpin button next to any pinned message in the panel. The message remains in the channel history but is removed from the pinned list.
