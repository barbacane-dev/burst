# Direct Messages

Direct messages (DMs) are private conversations between two users.

## Starting a DM

Click the **+** icon next to "Direct Messages" in the sidebar. A list of all users appears. Click a user to start a conversation.

If you've messaged that user before, the existing DM reopens. DM creation is idempotent — there's always exactly one DM channel between two users.

## DM Behavior

- DMs appear in the "Direct Messages" section of the sidebar, labeled with the other participant's display name.
- DMs support all the same features as channels: file uploads, reactions, threads, pins, and search.
- You cannot leave a DM, but you can mute notifications (set to "nothing").

## Finding a DM

Scroll through the Direct Messages section in the sidebar, or use search (`Cmd+K` / `Ctrl+K`) to find messages from a specific person.
